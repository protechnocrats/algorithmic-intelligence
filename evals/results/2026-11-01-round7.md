## java-clinic: the first baseline

| | Baseline (this round) | With the skill (rounds 4 to 7, 11 sessions) |
|---|---|---|
| Probe: behavior differences | 0 | 0 in all 11 |
| **J9 on 60,000 colliding keys (untrusted partner uploads)** | **3.4 s → 12.0 s: the "optimization" is 3.5 times slower under attack** (a hash structure on non-comparable record keys) | none slower under attack: 10 sessions 2.7 s → 52 to 73 ms (a worst-case-safe structure), 1 left it unchanged |
| J1 roster batching | applied: 2,000 → 2 round trips, results unchanged | held for review in every session |
| J3 reminders | batched (39 requests), rate limit kept, results unchanged | batching held for review |
| J2, J5 | fixed | fixed |
| Cost | $0.32 | $0.93 to $1.19 |

The baseline fell into the hostile-input trap the case was built for: correct results, so ordinary tests pass, but quadratic behavior on attacker-chosen keys. None of the 11 skill sessions did: 10 made J9 fast with a worst-case-safe structure, 1 left it unchanged. In the other direction, the baseline applied two batching changes (J1, J3) that the skill held back as unverifiable. Both kept results identical in the probe. That is a cost of the skill's caution: correct, verifiable wins left for the developer to approve.

## Findings

1. **On the held-out fixture the skill prevented a real regression.** The baseline corrupted user-visible labels (RB2's aliasing trap); neither skill session changed behavior. Its report also lacked the review section and any consideration of untrusted input.
2. **On java-clinic the baseline fell into the hostile-input trap** (12 s on colliding keys, slower than the code it replaced); none of the 11 skill sessions did.
3. **The skill costs more and is more cautious:** $0.77 to $1.19 per session against $0.07 to $0.32, and it holds back some verifiable wins (J1, J3, RB1) for review. Whether that caution is too conservative for batching changes whose equivalence a fake client could show is worth a look.
4. **Write mode loads with the recommended line,** but the mode statement is still skipped.
5. **Limits:** one baseline per fixture and one or two skill sessions; Claude Code and Haiku only; the account's spend limit ended the round early.
