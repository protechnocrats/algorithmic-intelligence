# Sources for `skills/algorithmic-intelligence/references/techniques/sequences-dp-search.md`

Where each claim in that file comes from, for maintainers and reviewers. Not part of the installed skill. Rows marked folklore below have no standard published source: verify them against the project's own tests.

- Cormen, Leiserson, Rivest, and Stein, *Introduction to Algorithms*, 4th ed. (2022): dynamic programming, NP-completeness, approximation algorithms, counting inversions with merge sort.
- Donald E. Knuth, "Optimum Binary Search Trees," *Acta Informatica* 1(1), 1971, and F. Frances Yao, "Efficient Dynamic Programming Using Quadrangle Inequalities," STOC 1980: the Knuth optimization and the quadrangle inequality.
- Richard E. Korf, "Depth-First Iterative-Deepening: An Optimal Admissible Tree Search," *Artificial Intelligence* 27(1), 1985 (IDDFS and IDA*).
- Ellis Horowitz and Sartaj Sahni, "Computing Partitions with Applications to the Knapsack Problem," *Journal of the ACM* 21(2), 1974 (meet-in-the-middle).
- Folklore (competitive programming, no standard published source): Mo's algorithm, the convex hull trick and Li Chao tree, divide-and-conquer optimization, digit DP, sum-over-subsets DP, and persistent segment trees; see the Driscoll, Sarnak, Sleator, and Tarjan paper in `docs/sources/techniques/specialized-structures.md` for persistence in general.
- Marek Cygan et al., *Parameterized Algorithms* (2015).
- Donald E. Knuth, "Dancing Links" (2000), and *The Art of Computer Programming*, Vol. 4A (2011), section 7.2.1 (generating tuples, permutations, and combinations, including Gray codes and Algorithm L), Vol. 2, section 3.4.2 (random permutations, Algorithm P).
- David P. Williamson and David B. Shmoys, *The Design of Approximation Algorithms* (2011).
